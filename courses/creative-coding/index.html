01 · WHAT IS CREATIVE CODING?

Code can be a creative material.

Creative coding is the use of programming as part of the creative process — allowing designers to create visual systems, motion, interaction, generative graphics and digital experiences.

Students do not learn coding simply to become programmers. They learn computational thinking so they can translate design ideas into rules, systems and behaviours.

01

Idea → Algorithm

Break a visual or interactive idea into clear steps, relationships and rules.

02

Algorithm → System

Use repetition, variables, conditions and parameters to build systems that can generate and change.

03

System → Experience

Connect computation with interaction, data, sound, movement and digital media.

03 · EXPERIENCE THE TEACHING METHOD

Change a rule. Change the whole system.

Start with one simple visual rule. Change a parameter and watch the entire system respond.

const shape = "circle";
const scale = 24;
const spacing = 60;
const rotation = 0;

for (let row = 0; row < rows; row++) {
  for (let col = 0; col < cols; col++) {
    draw(shape,
      col * spacing,
      row * spacing,
      scale,
      rotation
    );
  }
}

    10 · TOOLS & INFRASTRUCTURE

    Start simple. Progress into real creative technology.

    Learning progression

    Algorithmic thinking → Scratch / Blockly / Code.org → Creative coding → JavaScript / p5.js → Interactive media → Web APIs / MediaPipe → Physical & immersive → Arduino / sensors / projection.

    What the institution needs

    Core activities require laptops or lab computers, a modern browser and internet access. Advanced modules can add webcams, microphones, microcontrollers, sensors and projection.

    13 · FAQ

    Common questions.

    Do students need to know how to code?

    No. The programme can begin with visual and algorithmic thinking before introducing professional programming tools.

    Do faculty need coding experience?

    No. Interactv can teach, co-teach or train faculty depending on the institution's preferred delivery model.

    Can this fit into an existing course?

    Yes. It can be delivered as a workshop, elective, module, studio component or semester programme.

    What infrastructure is required?

    Core activities require computers and a modern browser. Advanced activities can introduce cameras, audio, microcontrollers, sensors and projection.

    Can the curriculum be customised?

    Yes. Duration, projects, tools and assessment can be adapted to the institution's programme structure.
